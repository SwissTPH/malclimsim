# Create Long Format Data for Simulated Posterior Median and CI

Create Long Format Data for Simulated Posterior Median and CI

## Usage

``` r
summarize_simulation_ci(simulations, variables, ci_level = 0.95)
```

## Arguments

- simulations:

  List of simulation data frames.

- variables:

  Character vector of variable names.

- ci_level:

  Confidence interval width (e.g., 0.95).

## Value

Data frame in long format.
